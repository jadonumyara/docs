تتيح لك مكوّنات Mintlify إنشاء صفحات وثائق ثرية وتفاعلية باستخدام MDX. فيما يلي بعض المكوّنات الشائعة الاستخدام.

اطّلع على [نظرة عامة على المكوّنات](https://mintlify.com/docs/components) في وثائق Mintlify للحصول على قائمة كاملة.

## التنبيهات

استخدم التنبيهات لجذب الانتباه إلى المعلومات المهمة.

<Note>**Note** هي لمعلومات عامة تساعد القارئ.</Note>

<Tip>**Tip** تُسلّط الضوء على اختصار مفيد أو ممارسة فضلى.</Tip>

<Warning>**Warning** تُحدّد شيئًا قد يسبّب مشاكل.</Warning>

<Info>**Info** تنبيه يوفّر سياقًا إضافيًا.</Info>

```mdx
<Note>A **Note** is for general information that helps the reader.</Note>

<Tip>A **Tip** highlights a helpful shortcut or best practice.</Tip>

<Warning>A **Warning** flags something that could cause problems.</Warning>

<Info>An **Info** callout provides supplementary context.</Info>
```

## الخطوات

تعرض الخطوات الإجراءات المرقّمة بوضوح.

<Steps>
  <Step title="ثبّت الحزمة">
    ```bash
    npm install my-package
    ```
  </Step>
  <Step title="هيّئ">
    شغّل أمر التهيئة في جذر مشروعك.
    ```bash
    npx my-package init
    ```
  </Step>
  <Step title="أنت جاهز">
    ابدأ في استخدام الحزمة في الكود الخاص بك.
  </Step>
</Steps>

````mdx
<Steps>
  <Step title="Install the package">
    ```bash
    npm install my-package
    ```
  </Step>
  <Step title="Initialize">
    Run the init command in your project root.
  </Step>
  <Step title="You're ready">
    Start using the package in your code.
  </Step>
</Steps>
````

## مجموعات التعليمات البرمجية

يعرض `CodeGroup` مقتطفات تعليمات برمجية متعددة كعلامات تبويب — مثالي لعرض المثال نفسه بلغات متعددة.

<CodeGroup>
  ```typescript TypeScript
  const response = await fetch('https://api.example.com/users');
  const users = await response.json();
  ```

  ```python Python
  import requests
  response = requests.get('https://api.example.com/users')
  users = response.json()
  ```

  ```bash curl
  curl https://api.example.com/users
  ```
</CodeGroup>

````mdx
<CodeGroup>
  ```typescript TypeScript
  const response = await fetch('https://api.example.com/users');
  ```

  ```python Python
  response = requests.get('https://api.example.com/users')
  ```
</CodeGroup>
````
