شريط الأدوات السياقي هو شريط إجراءات عائم يظهر على كل صفحة من وثائقك. يتيح للقرّاء نسخ محتوى الصفحة فورًا، أو فتحها في مساعد ذكاء اصطناعي، أو إضافة وثائقك كخادم MCP — دون مغادرة الصفحة.

اضبطه في `docs.json` تحت `contextual.options`:

```json docs.json
{
  "contextual": {
    "options": ["copy", "view", "claude", "chatgpt", "mcp", "cursor", "vscode"]
  }
}
```

## الخيارات المتاحة

### إجراءات المحتوى

| الخيار | الوصف |
|--------|-------------|
| `copy` | ينسخ الصفحة كـ Markdown إلى الحافظة |
| `view` | يفتح إصدار Markdown الخام للصفحة (عنوان URL بامتداد `.md`) |

### مساعدو الذكاء الاصطناعي

| الخيار | الوصف |
|--------|-------------|
| `claude` | يفتح الصفحة في Claude |
| `chatgpt` | يفتح الصفحة في ChatGPT |
| `perplexity` | يفتح الصفحة في Perplexity |
| `grok` | يفتح الصفحة في Grok |
| `aistudio` | يفتح الصفحة في Google AI Studio |

### تكاملات المحرّر

| الخيار | الوصف |
|--------|-------------|
| `cursor` | يضيف الصفحة إلى سياق Cursor |
| `vscode` | يضيف الصفحة إلى VS Code Copilot |
| `windsurf` | يضيف الصفحة إلى Cascade في Windsurf |
| `devin` | يفتح الصفحة في Devin |

### MCP

| الخيار | الوصف |
|--------|-------------|
| `mcp` | يعرض تعليمات استخدام وثائقك كخادم MCP |
| `add-mcp` | يوفّر مطالبة بنقرة واحدة لإضافة خادم MCP لوثائقك إلى أداة ذكاء اصطناعي |

<Tip>
  الخياران `mcp` و`add-mcp` قويّان بشكل خاص — إذ يتيحان للمطوّرين توصيل موقع وثائقك بالكامل بأي مساعد ذكاء اصطناعي متوافق مع MCP، بحيث يمكنه الإجابة عن الأسئلة المتعلقة بمنتجك مباشرة.
</Tip>

## الخيارات المخصّصة

يمكنك إضافة إدخالات مخصّصة إلى شريط الأدوات بعنوان ووصف وأيقونة ورابط. يدعم `href` عناصر نائبة ديناميكية:

| العنصر النائب | يتم استبداله بـ |
|-------------|-------------|
| `$page` | عنوان URL الكامل للصفحة الحالية |
| `$path` | مسار الصفحة الحالية |
| `$mcp` | عنوان URL لخادم MCP الخاص بوثائقك |

```json docs.json
{
  "contextual": {
    "options": [
      "copy",
      "claude",
      {
        "title": "Open issue",
        "description": "Report a problem with this page",
        "icon": "github",
        "href": "https://github.com/your-org/docs/issues/new?title=Issue+on+$path"
      }
    ]
  }
}
```

<Note>
  يكون شريط الأدوات السياقي مرئيًا فقط في عمليات النشر للمعاينة والإنتاج، وليس في المعاينة المحلية `mint dev`.
</Note>

## الإقران مع Visibility

تكشف خيارات `copy` و`view` في شريط الأدوات محتوى صفحتك بصيغة Markdown مباشرة. إذا استخدمت مكوّن [`Visibility`](/agent-ready/visibility)، فإن كتل `for="agents"` ستُضمَّن في تلك الـ Markdown — مما يمنح مساعدي الذكاء الاصطناعي سياقًا منظّمًا لا يراه القرّاء البشر.
