Os componentes da Mintlify permitem que você crie páginas de documentação ricas e interativas usando MDX. Aqui estão alguns dos mais utilizados.

Veja a [visão geral de componentes](https://mintlify.com/docs/components) na documentação da Mintlify para uma lista completa.

## Callouts

Use callouts para chamar a atenção para informações importantes.

<Note>Um **Note** é para informações gerais que ajudam o leitor.</Note>

<Tip>Um **Tip** destaca um atalho útil ou uma boa prática.</Tip>

<Warning>Um **Warning** sinaliza algo que pode causar problemas.</Warning>

<Info>Um callout **Info** fornece contexto adicional.</Info>

```mdx
<Note>A **Note** is for general information that helps the reader.</Note>

<Tip>A **Tip** highlights a helpful shortcut or best practice.</Tip>

<Warning>A **Warning** flags something that could cause problems.</Warning>

<Info>An **Info** callout provides supplementary context.</Info>
```

## Cards

Os cards levam os leitores para outras páginas ou recursos.

<Columns cols={2}>
  <Card title="Referência da API" icon="terminal" href="/api-reference/introduction">
    Documentação gerada automaticamente a partir da sua spec OpenAPI.
  </Card>
  <Card title="Início rápido" icon="rocket" href="/quickstart">
    Coloque sua documentação no ar em três passos.
  </Card>
</Columns>

```mdx
<Columns cols={2}>
  <Card title="API reference" icon="terminal" href="/api-reference/introduction">
    Auto-generated docs from your OpenAPI spec.
  </Card>
  <Card title="Quickstart" icon="rocket" href="/quickstart">
    Get your docs running in three steps.
  </Card>
</Columns>
```

Use `<Columns cols={N}>` para controlar a largura da grade. Cards sem `href` são renderizados como painéis informativos.

## Etapas

As etapas apresentam procedimentos numerados de forma clara.

<Steps>
  <Step title="Instale o pacote">
    ```bash
    npm install my-package
    ```
  </Step>
  <Step title="Inicialize">
    Execute o comando de inicialização na raiz do seu projeto.
    ```bash
    npx my-package init
    ```
  </Step>
  <Step title="Tudo pronto">
    Comece a usar o pacote no seu código.
  </Step>
</Steps>

````mdx
<Steps>
  <Step title="Install the package">
    ```bash
    npm install my-package
    ```
  </Step>
  <Step title="Initialize">
    Run the init command in your project root.
  </Step>
  <Step title="You're ready">
    Start using the package in your code.
  </Step>
</Steps>
````

## Abas

As abas permitem que os leitores alternem entre conteúdos alternativos — diferentes linguagens, ambientes ou plataformas.

<Tabs>
  <Tab title="npm">
    ```bash
    npm install my-package
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add my-package
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add my-package
    ```
  </Tab>
</Tabs>

````mdx
<Tabs>
  <Tab title="npm">
    ```bash

  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add my-package
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add my-package
    ```
  </Tab>
</Tabs>
````

## Accordions

Accordions ocultam conteúdo atrás de um botão de alternância — úteis para FAQs ou detalhes opcionais.

<AccordionGroup>
  <Accordion title="O que este produto faz?">
    Uma resposta breve para a primeira pergunta. Seja conciso.
  </Accordion>
  <Accordion title="Como o preço é calculado?">
    Outra resposta aqui. Use o espaço de que precisar.
  </Accordion>
</AccordionGroup>

```mdx
<AccordionGroup>
  <Accordion title="What does this product do?">
    A brief answer to the first question.
  </Accordion>
  <Accordion title="How is pricing calculated?">
    Another answer here.
  </Accordion>
</AccordionGroup>
```

## Frames

Envolva imagens ou outros conteúdos em um `Frame` para adicionar uma borda estilizada e cantos arredondados.

<Frame>
  <img src="https://mintlify-assets.b-cdn.net/bigbend.jpg" alt="Paisagem de Big Bend" />
</Frame>

```mdx
<Frame>
  <img src="/images/screenshot.png" alt="App screenshot" />
</Frame>
```

## Grupos de código

O `CodeGroup` exibe vários snippets de código como abas — ideal para mostrar o mesmo exemplo em várias linguagens.

<CodeGroup>
  ```typescript TypeScript
  const response = await fetch('https://api.example.com/users');
  const users = await response.json();
  ```

  ```python Python
  import requests
  response = requests.get('https://api.example.com/users')
  users = response.json()
  ```

  ```bash curl
  curl https://api.example.com/users
  ```
</CodeGroup>

````mdx
<CodeGroup>
  ```typescript TypeScript
  const response = await fetch('https://api.example.com/users');
  ```

  ```python Python
  response = requests.get('https://api.example.com/users')
  ```
</CodeGroup>
````
